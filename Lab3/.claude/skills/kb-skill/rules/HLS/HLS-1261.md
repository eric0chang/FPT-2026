- Inside the region no clocks are added between operations, including reads/writes of function arguments, so their RTL order follows the code.
- `ap_wait()` (C/C++) or `wait()` (C++) marks an explicit clock; neither affects C simulation.
- Default `floating`: code outside the region may run in parallel with it (the region stays cycle accurate). `fixed`: nothing outside overlaps the region.
```cpp
send: {
#pragma HLS protocol fixed
  *req = 1;
  ap_wait();
  *req = 0;
}
```

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS protocol, pp. 542-543.
