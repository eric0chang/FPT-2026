- Pipelining reuses the same resources for the same function over time, so it must know each task's latency at compile time.
- When a task's latency is a function of its input, use the producer-consumer/streaming structure to get task-level overlap instead.

Source: UG1399 v2023.2, Ch.1 Design Principles > Pipelining Paradigm, p. 33.
