- Synthesis does not guarantee that union fields share registers; HLS picks the most efficient hardware.
```cpp
union { unsigned int u; float f; } cvt;
cvt.u = raw_bits;
float val = cvt.f;
```
- half: `static_cast<half>(bits16)` from a `short`; back with `static_cast<ap_uint<16>>(h)` or `static_cast<unsigned short>(h)`; from fixed point with `x.to_half()`; or helper `fp_struct<half>` (`data()`, `to_int()`) from `hls/utils/x_hls_utils.h`.

Source: UG1399 v2023.2, Ch.6 Data Types > Unions, pp. 120-122.
