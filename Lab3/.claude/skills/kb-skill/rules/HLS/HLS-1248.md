- depth describes test-bench data volume: it gives the maximum FIFO size of the adapter HLS generates for RTL co-simulation.
- It is usually optional, but for a pointer the tool has no size to use, so depth must provide it.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS interface, p. 526.
