- Calls in the body are not inlined, and the body follows the same canonical-body guidelines as a function region.
```cpp
void region(const int a[64], int z[64], int n) {
  for (int k = 0; k < n; k++) {
#pragma HLS dataflow
    int t[64];
    stage_a(a, t);
    stage_b(t, z);
  }
}
```
