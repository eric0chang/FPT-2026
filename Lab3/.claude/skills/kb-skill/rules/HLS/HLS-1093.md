```cpp
#ifdef USE_HEAP              // user macro, disabled for synthesis
  int *buf = (int *)malloc(64 * sizeof(int));
#else
  int buf_store[64];
  int *buf = buf_store;      // remaining code unchanged
#endif
```
Flow: enable the macro, run C simulation and save the output; disable it, rerun and compare; then synthesize with it disabled. The code that was verified is exactly the code that is synthesized.

Source: UG1399 v2023.2, Ch.7 Unsupported C/C++ Constructs > Dynamic Memory Usage, pp. 145-147.
