- R+W on a channel leaving Start or entering End: an interface argument is both read and written.
- Several channels with the same variable name (sort by channel name): multiple producers or consumers; Start/End accesses can usually be ignored.
- R→W (possibly R+W→W): a feedback loop; the channel type tells legal from illegal feedback.
- Fix the code and rerun C simulation to update the graph.
