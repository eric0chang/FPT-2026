`operator<<` prints the full value for any width. For C stdio, `to_string()` returns a std::string; its optional arguments are the radix and a bool that prints non-decimal radices as signed (default false = unsigned).
Manual conflict: its radix list names binary as the default, but its own no-argument example prints hex; passing the radix avoids depending on either.
```cpp
ap_int<80> v("8000000000000000ABCD", 16);
std::cout << std::hex << v << std::endl;
printf("%s\n", v.to_string(10).c_str());
printf("%s\n", v.to_string(16, true).c_str()); // signed hex
```

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Support for Console I/O (Printing), pp. 677-679.
