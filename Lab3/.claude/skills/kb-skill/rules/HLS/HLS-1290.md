summary: Initialize ap_[u]fixed from float/double literals only when that precision is enough - the stored value can be no more precise than the 32-bit float or 64-bit double constant; for more bits use a string initializer ("0b0.0101", "0b0101p-4", "0x5p-4") so every bit is set exactly.

```cpp
ap_ufixed<4,0> a = "0b0.0101";   // 0.3125, binary with a point
ap_ufixed<4,0> b = "0b0101p-4";  // same, binary mantissa * 2^-4
ap_ufixed<4,0> c = "0x5p-4";     // same, hex mantissa * 2^-4
```
Typical use: wide constants such as a 62-bit pi with 60 fraction bits, which a double literal cannot fully populate.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Initialization and Assignment from Constants (Literals), p. 704.
