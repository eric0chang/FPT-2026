id: HLS-1279
summary: When an ap_[u]int shift amount has a signed type (ap_int) and is negative, the shift runs in the opposite direction by its magnitude; use an unsigned (ap_uint) shift amount when only one direction is intended.

Each shift operator has one overload for an unsigned RHS and one for a signed RHS. Only the signed-RHS overloads reverse on a negative value: with `s == -3`, `x << s` acts like `x >> 3`. The result width is still the LHS width.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Shift Operators, pp. 675-685.
