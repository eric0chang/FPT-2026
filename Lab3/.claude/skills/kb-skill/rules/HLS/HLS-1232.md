---
id: HLS-1232
summary: Do not use BIND_STORAGE on top-level function arguments; set their memory type and implementation with the INTERFACE pragma's storage_type and storage_impl options, since that memory type decides how many and which RTL ports are created.
tags:

records: []

- BIND_STORAGE is for arrays/variables defined inside a function body.
- Example for local storage: `#pragma HLS bind_storage variable=coef type=ram_1p impl=bram`.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS bind_storage, pp. 506-507.
