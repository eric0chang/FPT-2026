- Validate the algorithm in C/C++ first; turnaround there is far quicker than in RTL.
- Build the test bench so that co-simulation of the generated RTL can reuse it; the RTL can additionally be fed into an existing RTL verification flow for wider coverage.
- Code Analyzer comes before synthesis, so legality and parallelism problems show up early.
