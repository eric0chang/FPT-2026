- ap_vld: valid only. An ap_vld input is captured as soon as valid is High, even before the block needs it, and held internally.
- ap_ack: acknowledge only; an output write stalls until the consumer acknowledges, but no signal says when the data can be taken.
- ap_hs: valid plus acknowledge. Inputs stall while valid is Low; outputs raise valid with the write, stall until ack, and drop valid on the next edge. Suits bottom-up and top-down flows without manual intervention.
- ap_ovld: for inouts; input half ap_none, output half ap_vld (the default for read-write pointers).

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Port-Level I/O: Wire Handshakes, pp. 202-208.
