- HLS recognises the element-by-element move as a shift operation and replaces the array with a shift register.
- More flexible than a FIFO: any position can be read each cycle, not only the head.
- The manual's listing stores the new value at `A[N]`, one past the end of an `N`-element array; the last valid slot is `N-1`.
```cpp
int win[TAPS];                 // inferred as a shift register
for (int n = 0; n < LEN; ++n) {
  for (int k = 0; k < TAPS - 1; ++k)
    win[k] = win[k + 1];       // shift
  win[TAPS - 1] = in[n];       // newest sample
  out[n] = win[sel[n]];        // read any tap
}
```
