- A single call leaves no interval between transactions for the RTL simulation to measure.
- Profiling supplies the Dataflow Viewer's channel data (e.g. FIFO sizes) and the per-process read-blocked, write-blocked and stall times.
- Many calls with varied data also widen verification coverage: a bench only checks what it exercises.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Writing a Test Bench; Dataflow Viewer, pp. 340-374.
