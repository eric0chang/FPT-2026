id: HLS-1246
summary: INLINE recursive in a DATAFLOW region is ignored when inlining everything would collapse the region into a single function that no longer meets the dataflow conditions.
tags:

- Symptom: the dataflow processes are still separate modules although `INLINE recursive` was applied.
- Cause: merging all processes into one function would break the dataflow region, so the tool drops the recursive inline.
- Fix: do not count on region-level recursive inlining inside a dataflow region; check the resulting hierarchy in the synthesis report.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS inline, p. 522.
