---
id: HLS-1282
summary: Do not use sizeof() to get the bit width of an ap_[u]int (or any AP class): it returns the object's storage in bytes (sizeof(ap_int<127>) and <128> are 16, <129> is 24); use the type's ::width member or .length() instead.

---
ap_[u]int is a C++ class, so sizeof reports how much host memory the object occupies, which grows in coarse steps, not the number of bits the type models. `T::width` gives the width at compile time; `x.length()` returns the total bit count of a variable.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Sizeof, pp. 687-694.
