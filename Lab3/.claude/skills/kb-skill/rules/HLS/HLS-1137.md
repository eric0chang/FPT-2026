- Word n sits at address n for ap_memory and at n times the word size in bytes for bram.
- Byte enables: always on bram; on ap_memory only when the word is a whole number of bytes.
- ap_memory adds a chip-enable and has no IP integrator memory-generator support; bram shows as one interface, so a single connection wires all of its signals.

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Port-Level I/O: Memory Interface Protocol, pp. 208-209.
