- Symptom: co-sim deadlock, or throughput below expectation.
- Cause: insufficient FIFO depth on a channel, or a process stalling while waiting for input (read blocked) or unable to push output (write blocked).
- Fix: use the highlighted channels and stall columns to locate the starved or blocked process, adjust (e.g. channel depth), and rerun co-simulation.
- The viewer is generated only when DATAFLOW is applied; after C synthesis alone it shows just the inferred structure and FIFO/PIPO channels, because dataflow behaviour is dynamic and timing data comes from co-simulation.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Synthesis > Dataflow Viewer, pp. 373-374.
