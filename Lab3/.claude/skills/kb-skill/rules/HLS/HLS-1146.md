- Pragma: `#pragma HLS interface mode=ap_ctrl_chain port=return`; allowed on a void function too.
- Defaults: ap_ctrl_chain in the Vitis kernel flow, ap_ctrl_hs in the Vivado IP flow, so a chain built in the Vivado IP flow needs ap_ctrl_chain set explicitly.
- ap_ctrl_chain and ap_ctrl_hs both run sequential or pipelined; chain adds an ap_continue input so the consumer can stall the block (a downstream block's ap_ready can drive it directly).
- Under ap_ctrl_none, ap_start/ap_idle/ap_ready/ap_done are tied High and optimized away.

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Execution Modes of HLS Designs > Block-Level Control Protocols, pp. 230-232.
