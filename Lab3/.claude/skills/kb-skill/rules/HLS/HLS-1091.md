summary: Use __SYNTHESIS__ only to drop non-synthesizable side code such as debug file writes, never to change what the design computes; otherwise C simulation and the synthesized RTL can disagree, and such bugs are hard to debug.

Any guarded code means the simulated and the synthesized sources differ. For functional rewrites (e.g. removing malloc) use a user-defined macro and confirm in C simulation that both variants produce the same results.

Source: UG1399 v2023.2, Ch.7 Unsupported C/C++ Constructs > System Calls, pp. 145-146.
