---
id: HLS-1082
summary: Cast pointers only between native C/C++ types (e.g. int* to char*); general pointer casts, such as writing a struct through its address reinterpreted as unsigned*, are not supported for synthesis, so assign each field instead.
tags:
  - group:hlskb
  - pointer
  - pointer-cast
  - struct
  - tool:vitis-hls
  - type:must-not
records: []
---
```cpp
struct { short lo; short hi; } s;
// *(unsigned *)&s = ~0u;   // general cast: not supported
s.lo = -1;                 // write each member with its own type
s.hi = -1;
```

Source: UG1399 v2023.2, Ch.6 Data Types > Pointers, pp. 131-147.
