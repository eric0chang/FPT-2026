summary: To make several port writes (e.g., a data value and its valid flag) change in the same clock cycle, enclose them in a { } region with #pragma HLS LATENCY min=0 max=0.

```cpp
{
#pragma HLS latency min=0 max=0
  *payload = word;
  *payload_valid = 1;
}
```
- Zero latency for the region groups these assignments into a single cycle.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS latency, p. 531.
