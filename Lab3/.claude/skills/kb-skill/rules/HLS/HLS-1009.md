- Task-level pipelining relies on instruction-level pipelining inside each task to keep the streams filled and busy.
- Once each task can overlap with itself, the throughput of a run is set by the lowest task throughput rather than by the largest task latency.
- Gaps in the data fed into the network lower its performance.

Source: UG1399 v2023.2, Ch.1 Design Principles > Combining the Three Paradigms, pp. 29-38.
