- Config example: `clock=8ns`, `clock_uncertainty=15%`.
- Synthesis Summary > Timing Estimate lists target period and uncertainty; per the manual, period minus uncertainty gives the estimated clock period.
- In the Schedule Viewer a dashed vertical line in each cycle marks the reserved margin.
- Trade-off: more uncertainty leaves more slack for back-end timing but less of each cycle for operations.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Synthesis > Specifying the Flow Target and General Settings, pp. 355-370.
