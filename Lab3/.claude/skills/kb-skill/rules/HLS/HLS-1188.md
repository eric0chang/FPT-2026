---
id: HLS-1188
summary: Do not execute DATAFLOW tasks conditionally (e.g. if/else choosing which loop runs): dataflow does not optimize them. Make every task run on every call and move the condition inside the loop body.
tags:
  - conditional
  - dataflow
  - group:hlskb
  - loop
  - tool:vitis-hls
  - type:must-not
records: []
---
- Example: `if (mode) LoopA(); else LoopB(); LoopC();` - data no longer flows from one loop to the next, so the loops are not optimized as dataflow.
- Rewrite: one loop that always runs and selects per iteration (`t[i] = mode ? x[i]*3 : x[i]*5;`), with the following tasks also unconditional.
- HLS issues a message when it detects conditionally executed tasks.

Source: UG1399 v2023.2, Ch.10 Optimizing Techniques and Troubleshooting Tips > Limitations of Control-Driven Task-Level Parallelism > Conditional Execution of Tasks, pp. 298-302.
