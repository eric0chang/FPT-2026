---
id: HLS-1089
summary: Do not leave operating-system calls (file I/O, getc, time, sleep, ...) in code to be synthesized; remove them or guard them with #ifndef __SYNTHESIS__. Display-only calls such as printf and fprintf(stdout,...) are ignored by synthesis.
tags:

  - group:hlskb

  - synthesis-macro
  - system-call
  - tool:vitis-hls

records: []
---
The synthesized function and its callees must hold the whole behaviour, with nothing delegated to the OS.
```cpp
#ifndef __SYNTHESIS__
  FILE *dbg = fopen("mid.txt", "a");  // C simulation only
  fprintf(dbg, "%d\n", mid);
  fclose(dbg);
#endif
```

Source: UG1399 v2023.2, Ch.7 Unsupported C/C++ Constructs > System Calls, pp. 144-145.
