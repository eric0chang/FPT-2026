- The top decides which RTL ports are created and which sub-functions are pulled into the component.
- Example: a wrapper calls `stage_a` then `stage_b`; with `stage_a` as top, the wrapper and `stage_b` become bench code that drives and checks it.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Design Files and Test Bench Files, pp. 343-357.
