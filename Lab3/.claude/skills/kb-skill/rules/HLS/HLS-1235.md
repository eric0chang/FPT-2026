- Dual-port binding is for bandwidth: in the split form the producer uses one port and the consumer two ports of different banks.
- Check the HLS info message: it mentions a "single memory for all blocks" (merged) or a "separate memory for each block" (split).

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS bind_storage, p. 507.
