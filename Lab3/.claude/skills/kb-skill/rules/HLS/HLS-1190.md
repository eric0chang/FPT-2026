summary: In a pipelined function, a static variable that is conditionally written and then read in the same iteration can create a loop-carried dependency that forces II=2; use a local temp so each iteration does only one access (write or read) of the static.

- Symptom: the pipeline cannot reach II=1.
- Cause: when HLS cannot optimize the pattern, the store needs one cycle and the following load another, and the static (usually a register) links consecutive iterations.
- Fix, which allows II=1:
```cpp
static int last = 0;
int cur;
if (valid) { last = in; cur = in; }  // write only
else       { cur = last; }           // read only
out = cur;
```

Source: UG1399 v2023.2, Ch.10 Optimizing Techniques and Troubleshooting Tips > Limitations of Pipelining with Static Variables, pp. 303-304.
