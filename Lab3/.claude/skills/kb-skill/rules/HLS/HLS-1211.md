id: HLS-1211
summary: Do not drive co-simulation with run-time random stimulus (std::random_device, or a seed taken from the clock); fix the seed, or generate the random vectors once, store them in a file and let the C test bench read that file.

- The manual lists random input vectors such as `std::random_device` as unsupported for C/RTL co-simulation.
- A seed that varies per run (e.g. time-based) produces different input data each time the test bench executes, so results can vary between runs.
- The test bench runs in the first phase to record input vectors and its `main()` runs again for post-checking (`COSIM 212-302`, then `COSIM 212-316`), so stimulus must be reproducible.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C/RTL Co-Simulation, pp. 375-390.
