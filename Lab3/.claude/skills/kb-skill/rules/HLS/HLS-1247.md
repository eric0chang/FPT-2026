summary: Use the INTERFACE pragma only on arguments and the return of the top-level function; it is not supported on sub-functions, whose port protocols Vitis HLS derives automatically (the only control there is whether a port is registered).

- RTL ports of the top function are derived from argument type and direction, the flow_target, config_interface defaults, and INTERFACE pragmas.
- Each top-level argument may get its own I/O protocol, so it can connect to other hardware blocks speaking the same protocol; block-level control modes (ap_ctrl_*) are set on `port=return`.
- For sub-functions there is nothing to specify: the tool generates their ports and infers the protocol.
Also covered in UG1399 Ch.10 Optimizing Techniques and Troubleshooting Tips, p. 246.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS interface, pp. 524-525.
