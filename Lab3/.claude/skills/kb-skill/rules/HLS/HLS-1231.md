- Multi-stage versions exist for the basic arithmetic operations (add, subtract, multiply, divide) and for all floating-point operations.
- More limits: fadd fabric 0-13, fdiv fabric 0-29, fsqrt fabric 0-29, dmul maxdsp 0-14, ddiv fabric 0-58, drsqrt fulldsp 0-111.
- Comparison operators are LUT-only, so neither bind_op nor config_op can move them to DSPs.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS bind_op, pp. 503-505.
