Symptom: reads and writes of the array are placed in alternating cycles, giving II=2, although the two indices are only used when they differ.
- `type=inter` (the default): dependence across iterations of the same loop; false lets operations of different iterations run concurrently when the loop is pipelined or (partially) unrolled.
- `type=intra`: dependence inside one iteration (e.g. same array touched at start and end); false lets HLS move those operations freely, possibly helping performance or area.
- Left as true, operations keep their source order.
- Intra example: `#pragma HLS DEPENDENCE variable=bins type=intra direction=RAW dependent=false`
- direction (RAW/WAR/WAW) is for loop-carried dependences; distance= only applies to loop-carried ones declared true.
```cpp
for (int k = 0; k < M; k++) {
#pragma HLS dependence variable=hist type=inter false
#pragma HLS pipeline II=1
  hist[idx[k]] += 1;  // idx values guaranteed distinct
}
```
