- Process TIs are a key factor in region performance; the process with the largest TI is the slowest and limits the whole region.
- Performance Guidance names blocking factors per loop or function call (e.g. cyclic dependencies, memory port contention); decide per issue based on feasibility, location and the performance goal.
- The TI/II annotations next to calls and loops show how a process TI was derived.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Using Code Analyzer > Use Cases, pp. 350-352.
