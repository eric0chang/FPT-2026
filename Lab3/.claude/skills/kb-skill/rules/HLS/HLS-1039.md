Symptom: requested II not met, or pipelining dropped and the loop implemented sequentially.
Cause: a scalar recurrence, where each pass must finish computing the variables (and the loop condition built on them) before the following pass may start.
Fix: these dependencies are hard for the tool and typically need code changes; aim to compute whatever the next iteration needs as early in the body as possible.
Loop dependencies occur for any data type and are especially frequent with arrays.

Source: UG1399 v2023.2, Ch.3 Loops Primer > Scalar Dependencies, pp. 64-73.
