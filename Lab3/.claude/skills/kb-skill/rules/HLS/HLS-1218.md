- Example reading from the manual: a PIPO marked empty for 68% of the run means the reading process is stalled that long.
- For waveforms use the Vivado simulator (`cosim.tool=xsim`) with `trace_level` `port` or `all`; `wave_debug` (xsim only) shows per-process dataflow activity, including `StallNoContinue` (process finished but still waiting for a continue from the adjacent process).
- Shortening the processes that dominate execution offers the largest overall gain.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Timeline Trace Viewer, pp. 376-388.
