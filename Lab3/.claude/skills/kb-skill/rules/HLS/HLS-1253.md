id: HLS-1253
summary: To bound the total latency of all iterations of a loop, place LATENCY max=<N> in a named { } region that encloses the loop; the bound then covers every loop operation even if the loop is unrolled.
tags:

```cpp
whole_loop: {
#pragma HLS latency max=20
  acc: for (int k = 0; k < n; k++) { /* ... */ }
}
```
- The manual's own loop example puts LATENCY max= in the loop body instead; use the enclosing region when the bound is meant for all iterations together.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS latency, pp. 530-531.
