---
id: HLS-1192
summary: The test bench must not wait for interactive user input during execution, because the HLS tool cannot talk to the running simulator; pass any run-time arguments when launching simulation (csim.argv) or read them from files.
tags:
  - argv
  - csim
  - group:hlskb
  - testbench
  - tool:vitis-hls
  - type:must-not
records: []
---
- main() may take command-line arguments; set them in the config file, e.g. `csim.argv=arg1 arg2`.
- A prompt such as a read from stdin cannot be answered while the bench runs, since the tool has no channel to the simulator.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Writing a Test Bench, pp. 337-339.
