summary: For cosim, a top-level interface array (or array in an interface struct) may carry at most one of: equal-size vertical map, reshape, dim-1 partition; and never horizontal map, different-size vertical map, array-to-stream map, or conditional AXIS access with register slice.

- These are the limits of automatic RTL verification, stated for Vivado IP mode; stacking several transformations on one interface array is not handled.
- Debug: if cosim fails and multiple directives touch one interface array, reduce them to a single supported one.
- For streaming at the top-level interface, declare `hls::stream` arguments rather than mapping arrays to streams.
```cpp
void filt(hls::stream<int> &din, hls::stream<int> &dout);
```

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Unsupported Optimizations for Co-Simulation, pp. 382-390.
