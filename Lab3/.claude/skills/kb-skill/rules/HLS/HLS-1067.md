- With `for (idx = ...)` where `idx` is a member, an UNROLL pragma on that loop fails.
- Global variables in classes can block optimizations in general; AMD advises against them. With local loop indices HLS can apply all optimizations.
```cpp
class Shifter {
  int taps[N];
public:
  void step(int in) {
    for (int i = N - 1; i > 0; --i) {  // local counter
#pragma HLS UNROLL
      taps[i] = taps[i - 1];
    }
    taps[0] = in;
  }
};
```
Also covered in UG1399 Ch.10 Optimizing Techniques and Troubleshooting Tips > Unrolling Loops in C++ Classes, pp. 297-298.
