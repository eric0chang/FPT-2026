- hls::stream arguments are ap_fifo by default; mode=axis on a plain element type only imitates AXI4-Stream.
- hls::axis<T, WUser, WId, WDest> lives in ap_axi_sdata.h; ap_axis wraps signed ap_int data, ap_axiu unsigned ap_uint data; T may be any type, ap_fixed included.
- Trimming: `hls::axis_data<int, AXIS_ENABLE_LAST>` keeps data plus TLAST; `hls::axis_data<int, AXIS_DISABLE_ALL>` keeps data only; `hls::axis_user<8>` carries TUSER without TDATA.
- Error case: AXIS_ENABLE_ALL while WUser/WId/WDest stay 0; pass non-zero widths, e.g. `hls::axis_data<int, AXIS_ENABLE_ALL, 2, 1, 1>`.
- axis_data/axis_user default to strict enablement, and the macros flag incomplete signal specifications.

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > How AXI4-Stream is Implemented, pp. 195-202.
