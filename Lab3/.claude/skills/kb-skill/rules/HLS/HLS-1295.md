- Indices span the whole word, fraction bits included: bit i weighs 2^(i-F) with F = W - I. In `ap_fixed<8,4>` bit 4 is the units bit, so setting it on 2.5 gives 3.5.
- Bit and range references are lvalues: assigning an `ap_uint` slice to `x.range(hi,lo)` or `x(hi,lo)` overwrites those bits directly, a way to load a raw bit pattern into a fixed-point variable.
- `x.length()` returns W and works on a type or a value.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Class Methods, Operators, and Data Members > Bit Operator, pp. 717-719.
