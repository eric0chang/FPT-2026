Symptom: a pipelined loop calling small helper functions gives different QoR than in Vivado HLS.
Cause: Vivado HLS inlined small functions automatically; Vitis HLS does so only if the scheduler decides inlining is needed to achieve II=1 in a loop pipelined with II=1.
Fix: request inlining yourself to restore the earlier behavior:
```cpp
static int scale(int v) {
#pragma HLS INLINE
  return v * 3;
}
```

Source: UG1399 v2023.2, Ch.31 Migrating from Vivado HLS to Vitis HLS > Behavior Differences in Inlining of Functions, p. 808.
