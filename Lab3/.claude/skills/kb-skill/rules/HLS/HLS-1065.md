- The top function becomes the top RTL module and its arguments become the interface ports; every sub-function that is not inlined becomes its own RTL module, with its own synthesis report and Verilog/VHDL file.
- The top is set with `syn.top=<name>` (or in the C Synthesis settings). A top can contain multiple sub-functions, e.g. a wrapper that calls an add/subtract stage followed by a shift stage.
- Do not just instantiate the class in the test bench; the test bench calls the wrapper function. A `static` object keeps its member state between calls.
```cpp
template<typename T> class Avg2 {
  T prev;
public:
  T operator()(T x) { T y = (x + prev) / 2; prev = x; return y; }
};
int top(int x) {        // plain, non-template top function
  static Avg2<int> f;   // class lives inside the top
  return f(x);
}
```
