id: HLS-1239
summary: Never declare a DEPENDENCE false unless you are sure no real dependence exists (a wrong false gives incorrect hardware), and always write true or false explicitly: an omitted value is assumed false with only a warning.

- A false dependence removes ordering HLS would otherwise enforce, so a real dependence declared false breaks results.
- Before declaring one, confirm for the given array, type (inter/intra) and direction that the dependence is genuinely true or false.
- Watch for the warning that the dependent value was not given.
Also covered in UG1399 Ch.3 Loops Primer > Removing False Dependencies to Improve Loop Pipelining, p. 73.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS dependence, pp. 514-515.
