- Flow: confirm the function is in the fixed-point list (trig, hyperbolic, exp/log, pow/sqrt, rounding, comparison and others), retype the arguments to `ap_[u]fixed`, run C sim, then synthesize.
- C sim uses the same bit-accurate types as the RTL, so it shows the real hardware precision.
```cpp
#include "hls_math.h"
#include "ap_fixed.h"
ap_fixed<24,4> phase = 1.5;
ap_fixed<24,4> y = hls::sin(phase);
```
