Pattern shown by the manual's test bench: sweep the inputs in a loop, write each result to a file with a fixed, high-precision format, diff that file against a golden file, and return non-zero from `main()` on a mismatch so the run reports failure.
Because the bit behaviour is the same before and after synthesis, quantization and overflow effects can be explored quickly in software without waiting for RTL.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > ap_[u]fixed example and test bench, pp. 696-697.
