- Synthesis has no pointer reinterpretation.
- Rewrite variable-selected member access so each statement names a fixed member:
```cpp
// unsupported
for (int i = 0; i < 4; ++i) y[i] = (i < 2 ? u.p.lo : u.p.hi) + x[i];
// supported
y[0] = u.p.lo + x[0];  y[1] = u.p.lo + x[1];
y[2] = u.p.hi + x[2];  y[3] = u.p.hi + x[3];
```
- Inside the design, unions remain usable for raw-bit conversion of native types (see the float bit-cast rule).

Source: UG1399 v2023.2, Ch.6 Data Types > Unions, pp. 121-122.
