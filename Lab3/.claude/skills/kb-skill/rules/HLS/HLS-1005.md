- Designing with streams means reasoning about the order in which data is accessed.
- A sequential pattern can become a one-way stream from a producer task to a consumer task, so both can process data at the same time.

Source: UG1399 v2023.2, Ch.1 Design Principles > Streaming Data Paradigm, p. 30.
