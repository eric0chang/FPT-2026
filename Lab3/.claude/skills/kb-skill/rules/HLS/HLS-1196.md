- Top-level statements of a function or loop body become processes and their data dependencies become channels, as if DATAFLOW were applied, even when no such pragma exists yet.
- Channel data volume and access mode come from profiling the C test bench run, so estimates depend on the bench data.
- Performance Guidance points out blockers such as cyclic dependencies and memory port contention.
- Trade-off: rapid architecture exploration without synthesis vs. lower fidelity than post-synthesis or post-implementation numbers.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Using Code Analyzer, pp. 346-352.
