---
id: HLS-1184
summary: In a DATAFLOW region, read the function's input ports at the start and write its output ports at the end; port accesses in the middle of the region can make the processes execute one after another instead of overlapping.
tags:

- Symptom: dataflow tasks run sequentially and throughput suffers.
- Cause: reads or writes of the function's arguments occur partway through the region.
- Fix: move all port reads to the beginning and all port writes to the end.
- HLS issues a message describing the situation when it detects this style.

Source: UG1399 v2023.2, Ch.10 Optimizing Techniques and Troubleshooting Tips > Limitations of Control-Driven Task-Level Parallelism > Reading from Inputs/Writing to Outputs, p. 298.
