- `to_ap_int()` returns an ap_int that holds all I integer bits with the fraction truncated (12.75 -> 12).
- `to_double()` / `to_float()` give IEEE double / float; `to_half()` gives the HLS 16-bit half type.
- `to_int64()` / `to_uint64()` return ap_slong / ap_ulong.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Explicit Conversion Methods, pp. 719-720.
