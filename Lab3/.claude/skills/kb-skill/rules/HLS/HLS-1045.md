- A top-level array argument becomes RTL ports to an external memory; the tool generates its address, data and control signals.
- An internal array also gets a memory model instantiated in the RTL, which downstream RTL synthesis then maps to memory.
- Complete partitioning into individual registers gives a fully parallel implementation, at the cost of the registers needed.
- Local on-chip memory answers in one or a few cycles; global DDR/HBM access takes many cycles.

Source: UG1399 v2023.2, Ch.4 Arrays Primer > Mapping Software Arrays to Hardware Memory, p. 83.
