- The manual marks the argument order as important: `#pragma HLS allocation function instances=f limit=2`, with the type first.
- An inlined function is no longer a separate block, so there is nothing to count or share.
- Template functions are identified by function pointer rather than by bare name.
- HLS auto-inlines small functions; INLINE off keeps such a helper as its own block so the limit can apply.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS allocation, pp. 496-497.
