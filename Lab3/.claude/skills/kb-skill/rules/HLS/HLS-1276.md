The manual flags this as important: modulus is not mapped to plain logic but to a divider IP core configured for the operation, so each % carries a divider's resources. The divider instances are visible in the generated RTL.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Binary Arithmetic Operators, p. 682.
