- As a general rule, loops left side by side inside one function are not inferred as parallel tasks; moving each into its own function (called, e.g., from a dataflow region) exposes them as tasks.
```cpp
void load(const int src[N], int mid[N]);   // loop 1
void store(const int mid[N], int dst[N]);  // loop 2
void top(const int src[N], int dst[N]) {
  int mid[N];
#pragma HLS dataflow
  load(src, mid);
  store(mid, dst);
}
```
