- Automatic pipelining is equivalent to writing `PIPELINE II=1` in that loop.
- In a nest the tool starts at the innermost loop and walks outward: when the parent can be pipelined as well, the child is unrolled into it and the parent is pipelined, then the next level is checked. Automatic pipelining can therefore land on an outer loop, with the inner loops unrolled into it.
- It runs after all user directives, so a loop already removed by UNROLL is no longer a candidate.
- `off` opts out a single loop; the config command adjusts the behaviour globally.

Source: UG1399 v2023.2, Ch.3 Loops Primer > Automatic Loop Pipelining, pp. 63-65.
