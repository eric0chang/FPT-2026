Function pointers are listed as unsupported under Pointer Limitations. Virtual functions carry a CAUTION, and the separate Virtual Functions and Pointers section marks them as not supported; Ch.33 (Unsupported Features > C Constructs) lists them again. Code that relies on them has to be rewritten before synthesis.
Ch.33 names pointer casts in the same list; the pointer-cast rule gives the precise limit (casts between native C/C++ types remain allowed, general casts such as reinterpreting a struct address are not).
Also covered in UG1399 Ch.33 Unsupported Features > C Constructs, p. 815.

Source: UG1399 v2023.2, Ch.7 Unsupported C/C++ Constructs > Virtual Functions and Pointers, pp. 147-149.
