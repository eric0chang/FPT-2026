- target_ti: cycles between successive starts of the loop (II x trip count). target_tl: cycles from the start of the first iteration to the end of the last.
- From a throughput goal: target_ti = clock frequency / required starts per second. Example: 200 MHz and 50 calls/s gives 4,000,000 cycles.
- Values may be given in cycles or seconds (unit=sec with ns/us/ps); a non-integer result is truncated with a warning.
- It is only a target; check the achieved interval in the reports. The manual route (PIPELINE/UNROLL placed at the right loop level) is still available; see the Loops Primer.
- In the manual's dataflow example every stage loop is bounded by a run-time `size` argument and carries `PERFORMANCE target_ti=32` together with `LOOP_TRIPCOUNT max=32`.
```cpp
for (int k = 0; k < len; k++) {
#pragma HLS LOOP_TRIPCOUNT max=64
#pragma HLS PERFORMANCE target_ti=64
  res[k] = src[k] - bias;
}
```
