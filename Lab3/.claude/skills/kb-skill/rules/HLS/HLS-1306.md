id: HLS-1306
summary: Do not use write_nb() on a stream mapped to an AXI4-Stream (axis) interface; axis supports only non-blocking reads, ap_fifo supports both. Top-level streams default to axis in the Vitis kernel flow and ap_fifo in the Vivado IP flow.

records: []
---
- In the Vivado IP flow a top-level stream can be switched from `ap_fifo` to `axis`, which brings the same write limitation.
- `read_nb()` remains usable on axis inputs.

Source: UG1399 v2023.2, Ch.23 HLS Stream Library > Non-Blocking API, pp. 735-741.
