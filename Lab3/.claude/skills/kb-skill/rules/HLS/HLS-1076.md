summary: ap_[u]int and ap_[u]fixed are capped at 1024 bits by default; to declare wider types, #define AP_INT_MAX_W (a positive integer, at most 4096) before ap_int.h is included, directly or through another header, otherwise the 1024-bit default applies.

```cpp
#define AP_INT_MAX_W 2048   // has to come before the header
#include "ap_int.h"
ap_uint<2048> wide_word;
```
Cost: very large values slow down software compilation and C simulation run time, so a setting above what the design uses only adds cost; raise it only for designs that really need words above 1024 bits.
Also covered in UG1399 Ch.20 Arbitrary Precision Data Types Library > Declaring/Defining ap_[u] Variables, pp. 672-676.

Source: UG1399 v2023.2, Ch.6 Data Types > Overview of Arbitrary Precision Integer Data Types, pp. 127-129.
