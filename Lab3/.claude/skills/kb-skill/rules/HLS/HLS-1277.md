Either direction of cast is acceptable; the requirement is that both results share one type.
```cpp
ap_int<20> pick(bool c, int i, ap_int<20> a) {
  return c ? ap_int<20>(i) : a;   // int -> ap_int
}
```
When the ap branch grows by a bit (e.g. `a + 1` on `ap_int<32>` is 33 bits), cast the int branch to the matching wider type, as the manual does with `ap_int<33>(i)`.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Ternary Operators, p. 684.
