summary: Before using a volatile arbitrary-precision (ap_*) variable in an arithmetic expression, assign it to a non-volatile variable and compute on that copy; volatile ap types are not supported in arithmetic.

```cpp
ap_uint<12> v = *vol_ptr;  // non-volatile copy of the volatile value
out = v + 1;               // arithmetic on the copy
```
