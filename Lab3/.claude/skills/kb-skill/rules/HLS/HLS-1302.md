- Streams can be local or global and can be passed between sub-functions; both internal and interface streams follow the by-reference rule. Include `hls_stream.h`.
- Accesses are strictly in order: once a value is read it is gone and cannot be read again.
```cpp
void stage(hls::stream<ap_uint<32>> &din,
           hls::stream<ap_uint<32>> &dout, int len);
```
