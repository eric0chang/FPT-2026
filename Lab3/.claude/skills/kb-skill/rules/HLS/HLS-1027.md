- Scalars always become FIFOs automatically.
- A PIPO always has room for everything produced in one iteration, so no sample is lost.
- FIFO channels let processes overlap within an iteration; PIPOs (together with FIFOs) give overlap across iterations.

Source: UG1399 v2023.2, Ch.2 Abstract Parallel Programming Model for HLS > Configuring Dataflow Memory Channels, pp. 50-53.
