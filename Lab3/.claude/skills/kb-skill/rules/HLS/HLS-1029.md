id: HLS-1029
summary: An array streamed as a FIFO in a DATAFLOW region can lose the strictly sequential accesses streaming relies on to compiler optimizations, dead code elimination especially; declaring it volatile may be needed to block them and keep streaming correct.

- A FIFO implementation is only correct while every access stays in sequential order.
- The manual says volatile might be necessary, not that it always is.

Source: UG1399 v2023.2, Ch.2 Abstract Parallel Programming Model for HLS > Specifying Arrays as PIPOs or FIFOs, p. 54.
