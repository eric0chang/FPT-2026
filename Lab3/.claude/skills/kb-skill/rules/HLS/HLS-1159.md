- Port width follows the declared type, not the value range: the example returns an `int` computed from chars, so the output port is 32 bits.
- Inside the design arrays default to block RAM (FIFO, distributed RAM or registers are other options); for a top-level array HLS assumes the block RAM is outside and generates its access signals.
- An FSM extracted from the C control flow drives those address/enable signals.

Source: UG1399 v2023.2, Ch.10 Optimizing Techniques and Troubleshooting Tips, pp. 251-253.
