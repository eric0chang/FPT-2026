id: HLS-1293
summary: When a narrower ap_[u]fixed is widened (assigned or combined into a larger width), it is sign-extended if the source is signed and zero-extended if unsigned; when the other interpretation is wanted, cast the source explicitly before widening.
tags:

Extension follows the signedness of the source value, not of the destination.
```cpp
ap_ufixed<4,4> u = 15;
ap_fixed<8,8>  w1 = u;                  // zero-extended: 15
ap_fixed<8,8>  w2 = ap_fixed<4,4>(u);   // reinterpret as signed first (wraps to -1)
```

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Expressions Involving ap_[u]fixed<> types, p. 707.
