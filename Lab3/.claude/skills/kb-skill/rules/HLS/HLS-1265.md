summary: #pragma HLS top name=<n> only labels a function (typically a class member function); you must still run set_top <n> (or select it as top in the project settings) for it to become the synthesized top.

- Once set_top uses the new name, that function and everything it calls are synthesized.
```cpp
void long_internal_name() {
#pragma HLS top name=core
  /* ... */
}
// then in Tcl: set_top core
```

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS top, p. 549.
