- Without it, the second run of the producer may write into the memory the consumer's first run is still reading.
- With runs overlapped, throughput is limited by the largest latency among the tasks instead of the sum of all task latencies.
- The latency of one run is unchanged; the total time for many runs drops.

Source: UG1399 v2023.2, Ch.1 Design Principles > Combining the Three Paradigms, p. 35.
