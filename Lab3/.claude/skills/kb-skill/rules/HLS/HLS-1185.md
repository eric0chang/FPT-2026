- If this is violated the tool cannot apply the dataflow model; HLS reports the violation in a message.
- Typical violation: one loop fills `buf` and two later loops both read `buf`.
- In the canonical-form guidelines scalars are exempt: they may be written then read, or read then written.
- Data should flow from a call to a lexically later one; backward flow needs streams (see the feedback rule).
- The call order is a canonical-form guideline: the checker warns by default (error with syn.dataflow.strict_mode=error), and non-canonical code is only implemented best-effort.
```cpp
void dup(int src[N], int a[N], int b[N]) {
  for (int i = 0; i < N; i++) { a[i] = src[i]; b[i] = src[i]; }
}
// produce(buf); dup(buf, b1, b2); useA(b1); useB(b2);
```
