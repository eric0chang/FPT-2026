- `<<` is overloaded for the full value range; `dec`, `hex`, `oct`, `setprecision`, `setw` and `setfill` are supported.
- `setprecision(n)` limits total significant digits (before plus after the point) and rounds the rest away: 3.14159 prints as 3.1416 at 5, and 123456 as 1.2346e+05. The default of 6 matches native float.
- `to_string()` takes an optional radix (2, 8, 10, 16) and a bool that prints the non-decimal formats as signed (default false: unsigned).
- Conflict: the manual lists 16 as the default radix, yet its own bare `to_string()` example prints binary (`0b011.010`); always pass the radix explicitly.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Support for Console I/O (Printing), pp. 705-707.
