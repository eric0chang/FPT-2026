- Expect messages like `[SYNCHK-101] Discarding unsynthesizable system call` naming each stream operator.
- An overloaded `operator<<` on a class can serve purely for display during C/C++ simulation.

Source: UG1399 v2023.2, Ch.6 Data Types > C++ Classes and Templates, pp. 113-120.
