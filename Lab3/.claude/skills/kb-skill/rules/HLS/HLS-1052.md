Inference rule: a local (non-global) static array that is completely written before it is read, and not written afterwards, becomes a ROM. Habits that help:
- initialize early in the function that uses the array;
- keep all initialization writes together, not mixed with other code;
- give each element a single value (no repeated stores to one element);
- compute values only from compile-time constants and the init-loop counter.
const variables are only read, so they get their value at declaration; const scalars typically reduce to constants, and constant propagation removes hardware that depends only on them.
Qualifiers guide synthesis rather than dictate it: HLS can also turn a non-const, non-static array into a ROM when its analysis finds that optimal.
Also covered in UG1399 Ch.6 Data Types > Type Qualifiers, p. 123.

Source: UG1399 v2023.2, Ch.4 Arrays Primer > Implementing ROMs, p. 95.
