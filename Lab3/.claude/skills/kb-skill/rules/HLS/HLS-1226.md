- Partition: each bank has its own ports, so more reads/writes per cycle and possibly higher throughput, at the cost of more memory instances or registers.
- Partitioning into blocks turns one array into several RTL RAMs; partitioning into elements turns each element into a register.
- Reshape: factor k gives 1/k the depth and k times the width, so one access returns k elements. This vertical remapping lowers block RAM usage instead of raising it.
- Packing order with factor=2: block reshape puts elements i and i+N/2 in one word; cyclic reshape puts 2i and 2i+1 in one word. Match the type to the elements your loop reads together.
Also covered in UG1399 Ch.4 Arrays Primer > Array Accesses and Performance > Array Partitioning, p. 86-88.
