---
id: HLS-1256
summary: Loops merge only if variable bounds have equal trip counts (no mix of variable and constant bounds), the code between them has no side effects, and none contains FIFO reads; with force, you must verify the merged loop yourself.
tags:

records: []
---
- Constant bounds may differ: the merged loop runs to the largest constant.
- Code between the loops must give the same result if executed repeatedly: `x = y;` is acceptable, `x = x + 1;` is not.
- Reads from a FIFO or FIFO interface have to stay in sequence, and merging would reorder them.
- `loop_merge force` merges even when HLS issues a warning.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS loop_merge, pp. 533-534.
