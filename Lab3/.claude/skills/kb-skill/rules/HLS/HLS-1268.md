The arbitrary precision types are C++ template classes defined in these headers, found under `$HLS_ROOT/include` of the install. The same headers ship as a standalone package (`xilinx_hls_lib_<release>.tgz` in that include directory) that may be used in your own sources.
This covers both the synthesizable code and the test bench; the manual's test bench includes the header as well.
```bash
g++ -I$HLS_HOME/include -o tb tb.cpp kernel.cpp
```
Also covered in UG1399 Ch.20 Arbitrary Precision Data Types Library > Compiling ap_[u]fixed<> Types, pp. 698-704.
