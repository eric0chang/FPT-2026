- Stages of 20/10/30 time units deliver a result every 30; with 20/20/20 the latency stays 60 but a result arrives every 20. Balancing improves throughput, not latency.
- Start from the processing rate each phase of the design must sustain, then check how each task on the critical path is pipelined.
- Simulation results can be inspected in the HLS GUI or a waveform viewer to spot such throughput gaps.

Source: UG1399 v2023.2, Ch.1 Design Principles > Pipelining Paradigm, pp. 31-38.
