Symptom: high bits are missing after a left shift although the destination is wide enough.
Cause: the shift is evaluated at the LHS width and only afterwards extended into the destination.
Fix (AMD recommendation): cast the shifted expression to the destination type.
```cpp
ap_uint<6>  b = 0x21;
ap_uint<12> r1 = b << 4;               // 0x010: top bit of b lost
ap_uint<12> r2 = ap_uint<12>(b) << 4;  // 0x210
```
A right shift of a signed LHS copies the sign bit into the vacated upper positions.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Shift Operators, pp. 684-685.
