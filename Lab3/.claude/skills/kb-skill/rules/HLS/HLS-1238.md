summary: DATAFLOW is not hierarchical: tasks nested inside a sub-function or loop of a dataflow region are only overlapped if you also add DATAFLOW to that sub-function or loop, or inline the sub-function into the dataflow region.

- The pragma only turns the functions/loops directly in its own region into concurrent tasks.
- Example: DATAFLOW inside an outer loop body lets a consumer loop nest start before the producer nest has filled the whole buffer.
```cpp
outer: for (int t = 0; t < NT; ++t) {
#pragma HLS dataflow
  fill: for (int i = 0; i < B; ++i) {
#pragma HLS pipeline
    s >> buf[i];
  }
  drain: for (int i = 0; i < B; ++i) {
#pragma HLS pipeline
    mem[t * B + i] = buf[i];
  }
}
```
Also covered in UG1399 Ch.10 Optimizing Techniques and Troubleshooting Tips > Limitations of Control-Driven Task-Level Parallelism, p. 302.
