Symptom: a fixed-point division result has fewer fractional bits than the variable it is stored into.
Cause: binary points of operands with different formats are aligned automatically, but the quotient's fraction is limited by the dividend's.
Fix: cast to the new, wider width before assigning the result.

Source: UG1399 v2023.2, Ch.6 Data Types > Overview of Arbitrary Precision Fixed-Point Data Types, p. 128.
