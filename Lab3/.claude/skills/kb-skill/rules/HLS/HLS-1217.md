- Different input data may yield different cosim numbers.
- Non-pipelined: latency is counted from `ap_start` to `ap_done`; the next inputs are read one cycle after all work ends, hence the +1.
- Pipelined: new inputs can be taken before earlier transactions finish; latency is input-to-output cycles and II is the gap between `ap_ready` signals, which request new inputs.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Analyzing RTL Simulations, p. 383.
