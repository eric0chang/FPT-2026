---
id: HLS-1262
summary: Class members are reset only via the RESET pragma (config settings skip them): target public members, never from a constructor; inside a method only static members work; on an object in the top/sub-function a non-static member works only if the object is static.
tags:
  - class
  - group:hlskb
  - reset
  - static
  - tool:vitis-hls
  - type:must
records: []
---
```cpp
struct Acc {
  static int total;  // public static
  int last;          // public, non-static
  void step() {
#pragma HLS reset variable=total   // works; 'last' would not
  }
};
int Acc::total = 0;
void top() {
  Acc a; static Acc sa;
#pragma HLS reset variable=sa.last  // works: sa is static
  // a.last cannot be reset: neither it nor 'a' is static
}
```
- Private members cannot take the RESET pragma.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS reset, pp. 544-545.
