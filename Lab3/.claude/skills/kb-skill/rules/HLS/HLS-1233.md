- RAM_1P, RAM_1WNR, RAM_2P: AUTO, BRAM, LUTRAM, URAM. RAM_S2P: BRAM, BRAM_ECC, LUTRAM, URAM, URAM_ECC. ROM_1P/ROM_2P: AUTO, BRAM, LUTRAM.
- A FIFO with no impl given behaves as AUTOSRL, a value you cannot write explicitly.
- Because config_storage is FIFO-only, RAM/ROM bindings are made per variable with bind_storage.
