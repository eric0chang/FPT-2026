---
id: HLS-1133
summary: Do not return a pointer from the top-level function; a top-level return value becomes the ap_return output port, whose data is valid when ap_done is asserted.
tags:

ap_done marks the end of one transaction (one C function call) and at the same time qualifies ap_return, so return values need no separate valid signal.

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Port-Level Protocols for Vivado IP Flow, pp. 203-204.
