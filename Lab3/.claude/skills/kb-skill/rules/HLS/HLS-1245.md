- `INLINE` (no option) in function F: F is merged upward into whoever calls F; F's own callees are left alone (default depth is one level).
- `INLINE recursive` in F: works downward, inlining every function called within F at any depth.
- `INLINE off` in G: G is not inlined, overriding recursive inlining from above and automatic inlining.
```cpp
void helper(int &v) { v += 1; }
void keep_me(int &v) {
#pragma HLS inline off
  v *= 3;
}
void parent(int &v) {
#pragma HLS inline recursive
  helper(v);    // inlined, with anything it calls
  keep_me(v);   // stays a separate module
}
```

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS inline, pp. 522-523.
