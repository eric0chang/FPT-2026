The manual's example turns `static ap_fixed<32,0> tbl[32][D]` into `static int tbl[32][D]`. The concern is tool run time during ROM synthesis with ap_[u]fixed element types.

Source: UG1399 v2023.2, Ch.6 Data Types > Overview of Arbitrary Precision Fixed-Point Data Types, p. 130.
