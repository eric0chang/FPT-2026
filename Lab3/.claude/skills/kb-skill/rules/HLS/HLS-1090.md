summary: Never #define or #undef __SYNTHESIS__ yourself, in source or through compiler options, and do not use it in the test bench; the tool defines it only for synthesis, and C simulation and co-simulation do not honour it.

Defining or undefining the macro manually can make compilation fail. Restrict its use to the code that is synthesized.
The macro exists to separate synthesis-only from simulation-only code inside the design; test bench code is never synthesized.
Also covered in UG1399 Ch.4 Arrays Primer > C Simulation with Arrays, p. 97.

Source: UG1399 v2023.2, Ch.7 Unsupported C/C++ Constructs > System Calls, p. 144.
