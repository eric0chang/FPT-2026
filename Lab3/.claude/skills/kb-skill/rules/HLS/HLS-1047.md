Source rewriting is not always needed: array pragmas (partition/reshape) are the usual route and keep code changes minimal. Hand-coding the access pattern is for cases where it is needed to hit performance or gives better QoR.
```cpp
int acc = 0;
int w0 = buf[0], w1 = buf[1];
WIN: for (int k = 2; k < LEN; k++) {
  int w2 = buf[k];      // single array read
  acc += w0 + w1 + w2;
  w0 = w1;
  w1 = w2;
}
```
