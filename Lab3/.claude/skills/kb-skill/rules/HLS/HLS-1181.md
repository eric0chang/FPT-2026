- Each operator you want to control needs its own variable.
```cpp
int xy;
#pragma HLS BIND_OP variable=xy op=mul latency=3
xy = x * y;       // this multiply gets the 3-stage multiplier
*out = xy * z;    // left to the tool
```

Source: UG1399 v2023.2, Ch.10 Optimizing Techniques and Troubleshooting Tips > Managing Area and Hardware Resources > Controlling Hardware Implementation, p. 294.
