summary: Do not put single-producer-consumer violations, feedback between tasks, conditionally executed tasks, or loops with multiple exit conditions in a DATAFLOW region: HLS then just issues a message and skips the DATAFLOW optimization.
tags:
  - dataflow

- DATAFLOW needs data to move forward from one task to the next; these patterns break that.
- Check the synthesis log for the dataflow message; if present, tasks run sequentially.
- More detail: Limitations of Control-Driven Task-Level Parallelism.

Source: UG1399 v2023.2, Ch.16 HLS Pragmas > pragma HLS dataflow, pp. 512-513.
