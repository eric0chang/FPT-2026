In the manual's example, three calls (two direct, one inside a wrapper) end up as a single instance, one-third of the original area.
```cpp
void wrap(int x, int y) {
#pragma HLS INLINE
  work(x, y + 1);
}
void top(int a, int b, int c, int d) {
#pragma HLS ALLOCATION function instances=work limit=1
  work(a, b);
  work(a, c);
  wrap(a, d);
}
```

Source: UG1399 v2023.2, Ch.5 Functions Primer > Function Inlining, pp. 98-99.
