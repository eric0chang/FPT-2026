Ch.33 lists both limits; Vitis HLS reports a warning or an error for unsupported features. AMD recommends the C++ types in place of the C ones.
Example: a Vivado HLS design declaring an `ap_uint<8192>` exceeds the Vitis HLS limit and has to be restructured into types of 4096 bits or less.

Source: UG1399 v2023.2, Ch.33 Unsupported Features > C Arbitrary Precision Types, p. 815.
