summary: A pipelined sub-function called inside a pipelined loop gets the caller's II, ignoring its own PIPELINE II; if the call sits in a branch taken once every k iterations, put OCCURRENCE cycle=k in that branch so it pipelines at II=k (k=N/M must be an integer).

- k = N/M: N = executions of the enclosing loop/function, M = executions of the conditional block; N must be an integer multiple of M (10 iterations, branch taken 2 times -> 5).
- The slower II exposes more resource sharing inside the callee and with other functions.
- Only the pipelined call is affected; ordinary memory reads/writes in the same branch are not.
```cpp
for (int n = 0; n < 32; n++) {
#pragma HLS pipeline II=1
  if ((n & 7) == 0) {          // taken 4 of 32 times
#pragma HLS occurrence cycle=8
    slow_fn(buf);
  }
}
```
