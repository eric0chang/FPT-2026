Both a doubly recursive (Fibonacci-style) function and a tail-recursive (GCD-style) one are rejected. The manual states that C++ templates can implement tail recursion, which makes synthesizable tail-recursive designs possible.
Functions may call other functions (each maps to a hardware component that can be instantiated several times); only recursion is excluded, so express recursive algorithms without it before synthesis.
```cpp
template<int N> struct Acc {
  static int f(int s, int x) { return Acc<N-1>::f(s + x, x); }
};
template<> struct Acc<1> {
  static int f(int s, int x) { return s + x; }
};
int top(int x) { return Acc<8>::f(0, x); }
```
Also covered in UG1399 Ch.1 Design Principles > Combining the Three Paradigms, p. 33.
Also covered in UG1399 Ch.6 Data Types > Templates, pp. 118-119.
