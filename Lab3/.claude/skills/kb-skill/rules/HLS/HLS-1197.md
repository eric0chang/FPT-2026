- Merging processes in the graph is only what-if exploration; only processes that are consecutive in the source can be merged, and any change you keep has to be re-coded by hand.
- Aim for a top-level dataflow region where each process is a single function call, preferably with plain variables or constants as arguments.
- Rerun C simulation afterwards to refresh the graph and metrics.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Using Code Analyzer > Working with the Graph, pp. 347-352.
