```cpp
typedef ap_fixed<14,5,AP_RND,AP_SAT> smp_t;
typedef ap_fixed<smp_t::width + 1, smp_t::iwidth + 1,
                 smp_t::qmode, smp_t::omode> smp_sum_t;
smp_t p, q;
smp_sum_t s = p + q;   // extra integer bit absorbs the carry
```
Changing only the base typedef then resizes every derived type consistently.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Compile Time Access to Data Type Attributes, pp. 720-721.
