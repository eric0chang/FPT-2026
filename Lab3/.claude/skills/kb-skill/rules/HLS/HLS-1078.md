Gains: no hand-written alignment code between differently formatted operands, selectable rounding and overflow behavior, and fast C-level study of quantization and overflow effects before synthesis, because simulation is bit-accurate to the synthesized result.
Cost: these class types take more memory during C simulation, which shows up with very large ap_[u]fixed arrays.
Keep floating point where its dynamic range is actually needed.
```cpp
typedef ap_fixed<12, 4>  in_t;    // 8 fractional bits
typedef ap_fixed<10, 6>  gain_t;  // 4 fractional bits
typedef ap_fixed<24, 12> out_t;
out_t scale(in_t x, gain_t g) { return x * g; }  // alignment by the types
```
Also covered in UG1399 Ch.20 Arbitrary Precision Data Types Library > C++ Arbitrary Precision Fixed-Point Types, pp. 670-695.
