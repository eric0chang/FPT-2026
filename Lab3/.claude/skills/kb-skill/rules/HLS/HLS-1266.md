summary: Use UNROLL skip_exit_check (with factor=) only if the trip count is a multiple of the factor: with variable bounds the check is removed and you must guarantee that and that no exit check is needed; with fixed non-multiple bounds HLS won't unroll and warns.

- Benefit: removes the exit test and control logic that partial unrolling otherwise adds, saving area and simplifying control.
```cpp
for (int i = 0; i < n; i++) {   // caller guarantees n % 4 == 0
#pragma HLS unroll factor=4 skip_exit_check
  y[i] = x[i] * gain;
}
```
