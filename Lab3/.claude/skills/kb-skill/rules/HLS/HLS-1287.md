Symptom of the defaults: negative results drift downward; a too-large value comes back small or with the wrong sign (signed wraps past the maximum to the minimum, unsigned to 0; -19 stored in `ap_ufixed<4,4>` gives 13).
Rounding options, storing 1.25 / -1.25 into `ap_fixed<3,2,Q,AP_SAT>` (LSB 0.5): AP_RND 1.5 / -1.0, AP_RND_ZERO 1.0 / -1.0, AP_RND_MIN_INF 1.0 / -1.5, AP_RND_INF 1.5 / -1.5, AP_TRN_ZERO 1.0 / -1.0. AP_RND_CONV goes to the nearest value and settles exact ties on the neighbour whose LSB is 0 (at LSB 0.25: 2.125 -> 2.0, 2.375 -> 2.5).
Overflow options, storing 19 / -19 into 4-bit types with I = 4: AP_SAT 7 / -8 (unsigned 15 / 0), AP_SAT_SYM 7 / -7 (unsigned 15 / 0), AP_SAT_ZERO 0 / 0, AP_WRAP_SM -4 / 2.
N > 0 in a wrap mode saturates the top N bits and keeps the sign, so positives stay positive and negatives negative.
Modes act only where a value is stored, so set them on the variables whose range or bias matters and compare LUT counts in the synthesis report.

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Quantization Modes and Overflow Modes, pp. 697-703.
