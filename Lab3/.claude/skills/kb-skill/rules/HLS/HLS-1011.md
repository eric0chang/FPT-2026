- Symptom: a loop over arrays or matrices does not reach the parallel execution expected from transformations such as pipelining or unrolling.
- Cause: data dependencies across iterations.
- Fix: in many such cases the code must be rewritten so iterations can run in parallel.

Source: UG1399 v2023.2, Ch.1 Design Principles > Combining the Three Paradigms, p. 33.
