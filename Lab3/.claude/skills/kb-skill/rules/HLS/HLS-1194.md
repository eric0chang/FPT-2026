- Config: one `tb.file=<path>` per file; `tb.cflags` / `tb.file_cflags` add compile flags for the bench.
- During C simulation the bench's input files are copied into `csim/build`, where `csim.exe` runs and where any files the bench writes appear.
- Separate design and bench files are recommended, not required; the combined-file case only changes how the file is registered.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Simulation > Design Files and Test Bench Files, pp. 336-346.
