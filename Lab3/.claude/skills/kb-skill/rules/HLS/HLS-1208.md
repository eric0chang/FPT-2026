- Symptom: an optimization does not show up in the results as intended.
- Cause: the pragma was ignored or used differently than expected; otherwise this is only visible by digging through log files.
- Fix: find it in the Pragma Report, follow the link to the source, correct it and resynthesize. The Kernel Guidance report adds further design advice.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Synthesis > Synthesis Summary > Pragma Report, pp. 359-365.
