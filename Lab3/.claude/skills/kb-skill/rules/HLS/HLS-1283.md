Every ap_[u]int type exposes `static const int width` equal to its template width, usable as a compile-time constant in other template arguments.
```cpp
#define SAMPLE_W 10
typedef ap_uint<SAMPLE_W> smp_t;
typedef ap_uint<2 * smp_t::width> prod_t;   // product width = sum of widths
prod_t sq(smp_t s) { return s * s; }
```

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Compile Time Access to Data Type Attributes, p. 694.
