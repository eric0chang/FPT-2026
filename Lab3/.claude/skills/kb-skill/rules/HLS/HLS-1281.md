Bit 0 is the LSB; the highest valid index is width-1.
`range()` returns a proxy (`ap_range_ref`), not an ap_[u]int, so it lacks the class operators and methods, but it can be assigned to or from.
```cpp
ap_uint<16> w = 0x1234;
ap_uint<4>  n = w.range(7, 4);   // 0x3
w(3, 0) = ap_uint<4>(0xF);       // w = 0x123F
ap_uint<4>  r = w.range(4, 7);   // 0xC: bits 7..4 reversed
bool odd = ap_uint<8>(w.range(15, 8)).xor_reduce();
```

Source: UG1399 v2023.2, Ch.20 Arbitrary Precision Data Types Library > Bit-Level Operations, pp. 688-689.
