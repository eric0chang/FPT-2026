- Without a reset, nothing in the RTL brings the variable back to its starting value: initialization happens once at configuration, reset each time the signal is applied. Returning statics to their initial values on reset is not the default.
- Reset option (syn.rtl.reset / config_rtl -reset): none (no reset), control (default; FSM and I/O-protocol registers, so the block can run right after reset), state (control plus registers and memories built from statics and globals), all (every register and memory).
- With `state` or `all`, every array in block RAM is restored after reset. Unlike power-up initialization, this explicit reset walks each address to rewrite it: many cycles for large arrays, more logic, and a reset added to every array.
- RESET pragma or directive (syn.directive.reset) overrides the global choice per variable: add a reset to one static or global (arrays included) while staying at none/control, or use `off` to exclude a variable when using state or all. Place it within the variable's lifetime.
- Polarity and synchronous/asynchronous reset are separate RTL settings.
```cpp
void top(int x) {
  static int hist[256];
#pragma HLS reset variable=hist off
  /* ... */
}
```
