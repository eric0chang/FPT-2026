Only these two limits are stated consistently. For pointer-to-pointer below the top level the manual contradicts itself: notes in the Pointers and Pointer Limitations sections say it is not supported, while the Pointers text says it synthesizes and that, when it is used in multiple functions, Vitis HLS inlines all functions using it, which can increase run time.
Legal pointer array (row starts of a 2-D array):
```cpp
int *row[R];
for (int r = 0; r < R; r++) row[r] = &mat[r][0];
acc += *(row[r] + c);
```
Also covered in UG1399 Ch.4 Arrays Primer > Mapping Software Arrays to Hardware Memory, p. 84.

Source: UG1399 v2023.2, Ch.6 Data Types > Pointers, pp. 131-147.
