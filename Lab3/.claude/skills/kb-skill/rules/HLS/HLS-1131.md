ap_none adds no hardware, but HLS may read the input in any cycle after the first one, as scheduled; ap_ready rises once all inputs have been read. Nothing marks when an ap_none output is valid, hence the read window between completion and the next ap_start. Arrays need a memory or streaming protocol (ap_memory by default).

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Port-Level I/O: No Protocol, pp. 202-204.
