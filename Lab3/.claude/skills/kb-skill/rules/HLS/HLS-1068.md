- `step<0,1>()` and `step<1,1>()` each keep their own static accumulator.
- In contrast, all instances of an ordinary class receive the same optimizations, as with functions.

Source: UG1399 v2023.2, Ch.6 Data Types > Templates, pp. 116-118.
