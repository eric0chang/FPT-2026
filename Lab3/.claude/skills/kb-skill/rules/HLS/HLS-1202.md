- The scheduler treats every operation (a float multiply or a single register alike) as one object and works hierarchically: loop bodies, then loops, then function contents.
- Runtime grows with the number of objects and with the amount of scheduling freedom.
- Use the optimization strategies of the Programmers Guide to decide where these transforms are truly required.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Running C Synthesis > Improving Synthesis Runtime and Capacity, pp. 359-360.
