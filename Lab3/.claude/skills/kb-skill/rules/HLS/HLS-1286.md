Fraction bits are W - I, so the LSB weighs 2^-(W-I) whatever the sign of I; the signed variants use two's complement.
A negative I stands for |I| implicit sign bits (signed) or zero bits (unsigned) just right of the binary point, so every stored bit is a lower-weight fractional bit; this avoids spending stored bits on positions that would only ever hold zeros or copies of the sign.
```cpp
ap_fixed<18,6>  coef;        // 6 integer bits incl. sign, 12 fractional
ap_ufixed<4,0>  frac;        // 0 .. 0.9375 in steps of 1/16
ap_ufixed<2,-2> tiny;        // bits weigh 2^-3 and 2^-4: 0..0.1875, step 0.0625
ap_fixed<3,0>   h = -0.375;  // sign bit at the 2^-1 position: range -0.5..0.375
```
`ap_ufixed<1,0>` can hold 0 or 0.5; `ap_ufixed<1,-1>` 0 or 0.25, because the single stored bit sits one place further right.
