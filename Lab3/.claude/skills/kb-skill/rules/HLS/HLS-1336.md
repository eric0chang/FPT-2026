Ch.33 lists these under top-level arguments with C data types. The same list has one more item, `ap_int<N>` (N 1-32768), with no further explanation. It is not turned into a ban here: p.815 states that C arbitrary precision types are unsupported and that C++ arbitrary precision types are limited to 4096 bits, so these pages do not clearly establish that C++ `ap_int` arguments are rejected.

Source: UG1399 v2023.2, Ch.33 Unsupported Features > Top-Level Function Argument, pp. 814-815.
