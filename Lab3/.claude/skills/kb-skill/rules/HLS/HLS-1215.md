summary: If cosim warns that a dependence you declared false with the DEPENDENCE directive actually exists, remove that directive; keeping it yields a functionally invalid design. Cosim checks such false-dependence claims automatically.

- Debug step: when cosim fails and the code uses DEPENDENCE, delete those directives and rerun; a pass afterwards points to a wrong TRUE/FALSE setting.
- `cosim.disable_deadlock_detection=true` turns off these checks together with deadlock detection; that hides the warning, not the problem.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Verification of DATAFLOW and DEPENDENCE, pp. 382-390.
