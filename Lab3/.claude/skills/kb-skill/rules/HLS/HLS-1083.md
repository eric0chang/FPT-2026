Wire, handshake and FIFO ports deliver data strictly in order from element zero, so code such as `acc += *(p + i + 1)` needs indexing those protocols cannot provide. An ap_memory port carries an address and supports non-sequential access. Pointer arithmetic remains usable with streaming interfaces only when it starts at index 0 and then advances sequentially.

Source: UG1399 v2023.2, Ch.6 Data Types > Pointers on the Interface, pp. 134-136.
