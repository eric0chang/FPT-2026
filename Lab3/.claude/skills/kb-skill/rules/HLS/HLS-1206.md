- Latency is given in cycles and in ns; Iteration Latency is for a single loop iteration.
- II counts cycles until new inputs can be applied; II equal to latency + 1 means successive transactions do not overlap.
- Manual example: an FSM with an entry state C0 plus three loop-body states C1->C2->C3 repeated per iteration gives iteration latency 3, loop II 3, loop latency 9, function latency 9, function II 10; the next input set waits for the whole previous run. PIPELINE is the directive that lets iterations overlap and lowers the interval.
- Trip Count reflects any unrolling, so it can differ from the C loop bound.
- Resource columns give estimated BRAM, DSP, FF and LUT usage.
Also covered in UG1399 Ch.10 Optimizing Techniques and Troubleshooting Tips, pp. 253-254.
