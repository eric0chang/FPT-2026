summary: Avoid plain (unsigned) long in synthesizable code: its width follows the host OS (64-bit on 64-bit OSes, 32-bit on Windows), so operator sizes and RTL change; use int/int32_t for 32-bit and long long/int64_t for 64-bit.

- Synthesis mirrors the host compiler's width for `long`, so identical source can produce differently sized operators, hence different RTL, depending on the machine running Vitis HLS.
- Symptom: operator or port widths differ between machines although the code did not change.
- Fix: exact-width types from `stdint.h` (`int8_t` ... `int64_t` and unsigned forms) or `int` / `long long` keep the hardware identical everywhere.

Source: UG1399 v2023.2, Ch.6 Data Types > Data Types, p. 102.
