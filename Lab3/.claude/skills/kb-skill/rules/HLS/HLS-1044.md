Cause: pipelining a loop or function unrolls every loop beneath it, and a loop whose iteration count is unknown at compile time cannot be fully unrolled, so pipelining above it is prevented too.
Fix: use the largest possible count as a fixed bound and make the body conditional; HLS then knows how much hardware to build (one guarded copy of the body per iteration when unrolled).
```cpp
acc_lp: for (int k = 0; k < MAXN; k++) {
  if (k < cnt) total += buf[k];
}
```

Source: UG1399 v2023.2, Ch.3 Loops Primer > Working with Variable Loop Bounds, pp. 81-82.
