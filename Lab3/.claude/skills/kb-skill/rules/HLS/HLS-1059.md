- Variable types set operator size, and therefore area and performance of the RTL.
- An 8-bit by 16-bit product needs only 24 bits; it is then sign-extended to the 32-bit output port.
- A narrow destination lets HLS drop upper bits early: only the low 8 bits of a 16-bit operand enter an add whose result is 8-bit.
- If all bits are used, the operator is full size: `int / (sign-extended char)` becomes a 32-bit divider, `long long % char` a 64-bit modulus.

Source: UG1399 v2023.2, Ch.6 Data Types > Standard Types, pp. 102-104.
