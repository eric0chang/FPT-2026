- Recommended rather than required. `static` also ensures HLS builds an RTL memory and lets the default initialization of static types apply.
- A static array keeps its values from one call to the next, which matches how a RAM behaves; initialization costs no runtime cycles even for large memories.
- Without `static`, the initializer acts like a write loop on each call (e.g. 1024 cycles for a 1024-entry single-port RAM).
```cpp
static short taps[8] = {3, -1, 7, 2, 2, 7, -1, 3};
```

Source: UG1399 v2023.2, Ch.4 Arrays Primer > Initializing and Resetting Arrays, pp. 93-94.
