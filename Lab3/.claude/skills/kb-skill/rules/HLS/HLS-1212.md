- SIM-345 targets `ap_ctrl_none` tops: cosim accepts them only if combinational, pipelined with interval 1, or using array-streaming / `hls::stream` ports. `hls::stream` arguments are implemented as `ap_fifo` automatically.
- ap_ctrl_hs provides start, idle, done and ready ports; ap_ctrl_chain adds a continue signal; ap_ctrl_none provides none of them. Block-level modes are attached to the function return, e.g. `#pragma HLS interface mode=ap_ctrl_none port=return`.
- If a block-less top fails this check, switch the block protocol to `ap_ctrl_hs`/`ap_ctrl_chain` where co-simulation is needed, or meet one of the other conditions.
Also covered in UG1399 Ch.16 HLS Pragmas > pragma HLS interface, p. 525.

Source: UG1399 v2023.2, Ch.12 Building and Running an HLS Component > Co-simulation Requirements for Interface Synthesis, pp. 380-381.
