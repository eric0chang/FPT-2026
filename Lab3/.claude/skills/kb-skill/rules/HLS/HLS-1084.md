Options the manual lists for modeling streaming data: (1) volatile pointers - the C test bench does not model unique accesses and RTL simulation with it may fail, though waveforms show correct accesses; (2) rewrite the code with explicit unique reads/writes; (3) use a streaming data type, the accurate model.

Source: UG1399 v2023.2, Ch.6 Data Types > Pointers on the Interface > Multi-Access Pointers on the Interface, pp. 136-140.
