---
id: HLS-1303
summary: Do not use a class or struct with member functions as the element type of an hls::stream or split/merge channel; use C++ native types, arbitrary-precision types (ap_int, ap_ufixed, ...) or plain structs built from them.
tags:

- Allowed element types: any native C++ type, any Vitis HLS arbitrary-precision type, or a user struct whose fields are of those kinds.
- hls::split / hls::merge channels inherit the same DATATYPE restriction as hls::stream.

Source: UG1399 v2023.2, Ch.23 HLS Stream Library > Using HLS Streams, pp. 737-760.
