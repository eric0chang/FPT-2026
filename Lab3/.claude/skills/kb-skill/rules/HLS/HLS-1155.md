- Asynchronous read: the read data can be used right away instead of a clock cycle later.
- Distributed RAM does not scale to large memories; above roughly 128 bits switch to BRAM/URAM.

Source: UG1399 v2023.2, Ch.9 Best Practices for Designing with M_AXI Interfaces, p. 245.
