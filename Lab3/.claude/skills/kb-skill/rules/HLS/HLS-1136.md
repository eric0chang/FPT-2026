- A requested dual-port interface may still be reduced to single-port when HLS finds no benefit.
- By default the read data (e.g. d_q0) is expected one cycle after the address and d_ce are applied.
- Writes drive d_ce and d_we together with the address and d_d0.
- Changing the memory type later can produce a different schedule and RTL, so fix it before the first synthesis.

Source: UG1399 v2023.2, Ch.8 Interfaces of the HLS Design > Port-Level I/O: Memory Interface Protocol, pp. 208-210.
