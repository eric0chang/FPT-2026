- Side channels are optional signals of the AXI4-Stream standard; naming the struct members after them is what lets the code reference and drive them.
- Vitis HLS handles side channels quite differently from Vivado HLS; re-check ported side-channel code against the 'AXI4-Stream Interfaces with Side-Channels' section, which lists the Vitis HLS limitations.

Source: UG1399 v2023.2, Ch.31 Migrating from Vivado HLS to Vitis HLS > AXI4-Stream Interfaces with Side-Channels, p. 805.
