- `ap_int<24> f(int a, int b)` returning `a*b` still produces a 32-bit multiplier whose output is truncated.
- With `a` and `b` declared `ap_int<12>`, the RTL uses a 24-bit multiplier even though the product passes through an `int` temporary.
- AMD advises giving correctly sized types to the parameters of every function down the hierarchy, so that local variables need no explicit sizing.

Source: UG1399 v2023.2, Ch.6 Data Types > Bit-Width Propagation, pp. 124-143.
