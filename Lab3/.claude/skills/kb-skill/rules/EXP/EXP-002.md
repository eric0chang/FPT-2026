id: EXP-002
summary: For a convolution over a streamed image, do not pipeline only a short inner MAC loop inside a non-pipelined pixel loop: every pixel then pays the pipeline fill and drain. Write the layer as one flat II=1 loop over (pixel, step), or pipeline the pixel loop itself.

Exception to HLS-1042 (pipeline the innermost loop): that advice holds when the inner loop is long; here the inner loop has 15-20 iterations and the pixel loop runs hundreds of times.
- One flat loop: iterate over pixels x steps per pixel (e.g. output channel x kernel row) at II=1; do the window update when step == 0; keep the nest perfect so it can flatten (HLS-1255).
- Latency then is about pixels x steps per pixel.
Observed in a past LeNet run: inner loop pipelined, pixel loop not: 58 cycles per pixel for 15 cycles of MAC work (conv1, 784 pixels -> 47,260 cycles), 145 for 20 (conv2).
